Primeira saída digital: LED

GPIO como saída digital e temporização.
▼

Montagem: GPIO 2 → resistor → LED → GND.

from machine import Pin
from time import sleep

led = Pin(2, Pin.OUT)

while True:
    led.value(1)
    sleep(1)
    led.value(0)
    sleep(1)
Desafios: altere o intervalo para 0,5 s. Depois faça o LED piscar 3 vezes rapidamente e permanecer 2 segundos apagado.
Questão: o que representam os valores 0 e 1 enviados ao GPIO?

Entrada digital: botão controlando LED

Leitura de GPIO, pull-up e tomada de decisão.
▼

Montagem: botão no GPIO 4 e LED no GPIO 2.

from machine import Pin
from time import sleep

led = Pin(2, Pin.OUT)
botao = Pin(4, Pin.IN, Pin.PULL_UP)

while True:
    if botao.value() == 0:
        led.value(1)
    else:
        led.value(0)

    sleep(0.05)
Desafios: inverta o comportamento do LED e depois faça o LED mudar de estado a cada novo pressionamento.

Explorando uma entrada analógica: ADC

Conversão analógico-digital e escala de valores.
▼

Conecte um potenciômetro a um pino com ADC e observe como a leitura muda.

from machine import ADC, Pin
from time import sleep

adc = ADC(Pin(34))

while True:
    valor = adc.read_u16()
    print(valor)
    sleep(0.5)

Registre o valor mínimo e o valor máximo observados. Depois converta a leitura para uma porcentagem entre 0% e 100%.
