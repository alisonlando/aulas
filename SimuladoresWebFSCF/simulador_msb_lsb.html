MSB

Most Significant Bit

É o bit de maior peso. Em uma palavra de 8 bits, ele ocupa a posição bit 7.

Peso: 27 = 128

Estado atual do MSB: 0

LSB

Least Significant Bit

É o bit de menor peso. Em uma palavra binária, ele ocupa a posição bit 0.

Peso: 20 = 1

Estado atual do LSB: 0

Como o valor decimal é calculado?

0 = 0

Ideia principal:
Alterar o MSB de 0 para 1 pode adicionar 128 ao número de 8 bits, enquanto alterar o LSB de 0 para 1 adiciona apenas 1. Por isso, um é chamado de mais significativo e o outro de menos significativo.
