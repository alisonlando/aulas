Simulador: Números Positivos e Negativos em Binário

Clique nos bits para alternar entre 0 e 1. O simulador usa 8 bits com complemento de 2, a forma mais comum de representar inteiros positivos e negativos nos computadores.

Palavra binária de 8 bits

O bit 7 (MSB) tem papel especial: em complemento de 2, seu peso é -128. Os demais bits possuem pesos positivos.

Número positivo

Quando o MSB = 0, o número é zero ou positivo.

Exemplo:

00000101₂ = +5₁₀

Número negativo

Quando o MSB = 1, o número é negativo na representação em complemento de 2.

Exemplo:

11111011₂ = −5₁₀

Como o valor é calculado?

0 = 0

Ideia principal:
Em complemento de 2, uma palavra de 8 bits representa valores de −128 a +127. O MSB possui peso −128. Assim, por exemplo:

11111011₂ = −128 + 64 + 32 + 16 + 8 + 2 + 1 = −5.
