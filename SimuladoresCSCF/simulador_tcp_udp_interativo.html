Etapas do TCP

  1. SYN — cliente solicita conexão
  2. SYN + ACK — servidor responde
  3. ACK — conexão estabelecida
  4. DATA #1 — dados numerados
  5. ACK #2 — confirmação
  6. DATA #2 — próximo segmento
  7. FIN — cliente pede encerramento
  8. ACK — servidor confirma
  9. FIN — servidor encerra seu lado
  10. ACK — encerramento concluído
